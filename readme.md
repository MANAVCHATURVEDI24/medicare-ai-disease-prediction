# Healthcare AI – Lab Report Disease Prediction

An AI-powered healthcare application that extracts laboratory values from medical reports using OCR and predicts the risk of multiple diseases using Machine Learning.

## Features

- Upload lab reports in PDF, JPG, or PNG format
- OCR-based extraction of laboratory values
- Automatic detection of missing health parameters
- Dynamic questionnaire that requests only missing information
- Risk prediction for:
  - Diabetes
  - Liver Disease
  - Cardiovascular Disease
- Interactive prediction dashboard
- End-to-end full-stack application

## Tech Stack

### Backend
- Python
- FastAPI
- Scikit-learn
- Pandas
- NumPy
- Pydantic
- PyMuPDF

### Frontend
- React
- Vite
- JavaScript
- CSS

## Project Structure

- `app/` – FastAPI backend
- `frontend/` – React frontend
- `ocr/` – OCR extraction and value parsing
- `patient/` – Patient data model
- `prediction/` – Disease prediction modules
- `questionnaire/` – Missing information questionnaire
- `models/` – Trained machine learning models
- `dataset/` – Datasets
- `training/` – Model training scripts
- `tests/` – Test files

## Workflow

- Upload a laboratory report
- Extract laboratory values using OCR
- Populate the patient data model
- Identify missing parameters
- Ask only the required questions
- Run disease prediction models
- Display risk predictions on the dashboard

## Installation

### Clone Repository

```bash
git clone https://github.com/uniyalswayam6912-alt/AI-lab-report-disease-prediction.git

cd AI-lab-report-disease-prediction
```

### Backend

```bash
python -m venv .venv

# Windows
.venv\Scripts\activate

pip install -r requirements.txt

uvicorn app.main:app --reload
```

### Frontend

```bash
cd frontend

npm install

npm run dev
```
