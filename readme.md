# \# Healthcare AI – Multi-Disease Prediction

# 

# An AI-powered healthcare application for laboratory report analysis and multi-disease risk prediction using Machine Learning.

# 

# \## Features

# 

# \- Upload medical laboratory reports

# \- OCR-based extraction of laboratory values

# \- Automatic identification of missing information

# \- Questionnaire for missing patient information

# \- Machine learning based disease-risk prediction

# \- Support for:

# &#x20; - Diabetes

# &#x20; - Liver Disease

# &#x20; - Cardiovascular Disease

# \- Interactive healthcare dashboard

#

#

# \- Scikit-learn

# \- NumPy

# \- Pydantic
